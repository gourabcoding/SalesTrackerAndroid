# Sales Tracker Android App — v1.0

Offline-first starter Android project based on the Sales & Profit spreadsheet.

Included:
- Local phone storage
- Quantity integer validation
- Ruminti/Oindrila seller dropdown
- Automatic buying/selling/final selling/profit calculations
- 60/40 seller profit split
- Date picker
- Customer details and remarks

Open the project in Android Studio and build an APK.
